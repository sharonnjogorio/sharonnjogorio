# Hi there, I'm Sharon Njogorio :)

I'm a final-year Informatics and Computer Science student at Strathmore University who builds human-centered software for real-world, under-served contexts.

What I care about most is where technology meets people: HCI, inclusive and sensory-safe design and ICT4D. I like building for the people who tend to be designed around rather than designed for. 

I work across the stack, from React on the front end to Java and Node on the back, with a bias toward accessibility, clarity and offline-first reliability.

- **Current Focus:** My final-year capstone, a neurodivergent-inclusive voice interaction system for early childhood learning
- **Learning & Exploring:** HCI, ICT4D, VR/AR
- **Core Interests:** Human-centered and inclusive design, accessibility, software for social impact
